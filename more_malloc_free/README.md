# C - More malloc, free

Task 0 - 0-malloc_checked.c Function that allocates memory using malloc and exits with status 98 if malloc fails.
Task 1 - 1-string_nconcat.c Function that concatenates s1 and the first n bytes of s2 into newly allocated memory.
Task 2 - 2-calloc.c Function that allocates memory for an array using malloc and sets every byte to zero.
Task 3 - 3-array_range.c Function that creates an array of integers containing all values from min to max, in order.
