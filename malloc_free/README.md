# C - malloc, free

Task 0 - 0-create_array.c Function that creates an array of chars and initializes it with a specific char.
Task 1 - 1-strdup.c Function that returns a pointer to a newly allocated copy of the string given as a parameter.
Task 2 - 2-str_concat.c Function that concatenates two strings into newly allocated memory, treating NULL as an empty string.
Task 3 - 3-alloc_grid.c Function that returns a pointer to a 2 dimensional array of integers initialized to 0.
Task 4 - 4-free_grid.c Function that frees a 2 dimensional grid previously created by alloc_grid.
