# Simple Calculator

## Compile

``
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator
```


## Run

```
./calculator
```


## Supported operations

```
Choose an option
1. Add
2. Subtract
3. Multiply
4. Divide
0. Quit
