# C - Hello, World

First C project: how gcc turns a .c file into a program (preprocess, compile, assemble, link) and how to print text with puts, printf and putchar.
0-preprocessor | Runs the C file in $CFILE through the preprocessor; output in file c
1-compiler | Compiles $CFILE without linking; output <name>.o
2-assembler | Generates the assembly code of $CFILE; output <name>.s
3-name | Compiles $CFILE into an executable named cisfun
