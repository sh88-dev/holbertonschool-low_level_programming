# C - More functions, more nested loops

0-isupper.c | _isupper: returns 1 if c is uppercase, 0 otherwise
1-isdigit.c | _isdigit: returns 1 if c is a digit (0 through 9), 0 otherwise
2-mul.c | mul: returns the product of two integers
3-print_numbers.c | print_numbers: prints 0 to 9, followed by a new line
4-print_most_numbers.c | print_most_numbers: prints 0 to 9 except 2 and 4, then a new line
5-more_numbers.c | more_numbers: prints 0 to 14 ten times, each followed by a new line
6-print_lines.c | print_lines: draws a line of n underscores, followed by a new line
7-print_diagonal.c | print_diagonal: draws a diagonal of n backslashes, followed by a new line
8-print_square.c | print_square: prints a size x size square of #, followed by a new line
9-fizz_buzz.c | program: prints 1 to 100 with Fizz, Buzz and FizzBuzz for multiples of 3 and 5 or both
10-print_triangle.c | print_triangle: prints a right-aligned triangle of #, followed by a new line
