# C - Functions, nested loops

## Files

main.h | Protoypes for all functions in this project
0-putchar.c | Prints _putchar with the _putchar function
1-alphabet.c | print_alphabet: prints the lowercase alphabet with _putchar
2-print_alphabet_x10.c | print_alphabet_x10: prints the lowercase alphabet 10 times
3-islower.c | _islower: returns 1 if c is lowercase, 0 otherwise
4-isalpha.c | _isalpha: returns 1 if c is a letter, 0 otherwise
5-sign.c | print_sign: prints + / 0 / - and returns 1 / 0 / -1
6-abs.c | _abs: return the absolute value of an integer
7-print_last_digit.c | print_last_digit: prints and returns the last digit of a number
8-24_hours.c | jack_bauer: prints every minute of the day from 00:00 to 23:59
9-times_tables.c | times_table: prints the 9 times table, starting with 0
